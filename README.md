# Budgetly

A privacy-friendly personal budgeting web app. Import a bank or credit-card CSV,
clean up categories, set monthly budgets, and see where the money went — all in
your browser, with no account and no server.

The application lives in [`budgetly-app/`](budgetly-app). See
[`budgetly-app/README.md`](budgetly-app/README.md) for setup, scripts,
architecture, the CSV format guide, the privacy model, and known limitations.

```bash
pnpm --dir budgetly-app install
```

```bash
pnpm --dir budgetly-app dev
```
